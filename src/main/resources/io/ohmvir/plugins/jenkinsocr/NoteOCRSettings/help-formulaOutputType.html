How the OCR model writes the note and its formulas:
  • LATEX: a LaTeX document segment. Its structure (sections, lists, emphasis) is converted to the note application's own formatting and formulas are kept as TeX. TikZ pictures, figures and tables cannot be converted and are kept as LaTeX source.
  • KATEX: Markdown with $...$ and $$...$$ formulas.
  • PURE_TEXT: plain text with formulas written in Unicode, for note applications that cannot render equations.
If the selected note provider cannot render equations, builds print a warning when LATEX or KATEX is selected.
